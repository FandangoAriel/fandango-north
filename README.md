# ציוד חוות פאנדנגו בצפון

אפליקציית ניהול מלאי לשלושת אתרי הצפון: **בית העמק**, **להבות חביבה** ו**כפר חסידים**.

הנתונים ההתחלתיים נלקחו מגיליון [ציוד לחוות פאנדנגו בצפון](https://docs.google.com/spreadsheets/d/1EgL_CEVPJHM3DmPElzR4hPJGGGMo4yQIHrucKhdN6XI/edit) (עדכון 9.9.2026, כפר חסידים מ-20.5.2026).

## מה יש באפליקציה

- סקירה של חוסרים, יחידות לספקה ומיכלים ממתינים
- מלאי ציוד לכל אתר, עם כמות בפועל / מלאי מקסימום / כמות לספק
- מיכלים משולטים לפי לקוח
- רשימת אספקה להדפסה או העתקה
- שמירה מקומית בדפדפן (בלי שרת או התחברות)

## הרצה מקומית

```bash
npm install
npm run dev
```

השרת עולה בכתובת [http://127.0.0.1:43187](http://127.0.0.1:43187).

## בנייה

```bash
npm run build
npm start
```
